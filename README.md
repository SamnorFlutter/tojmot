# Tojmot — цифровая версия игры «Тожмот»

Монорепо (npm workspaces):

| Пакет | Что это |
|---|---|
| `packages/engine` | Правила игры, генерация ходов, шах/мат/пат, нотация, ИИ (alpha-beta). Чистый TypeScript, без UI. Тесты — vitest. |
| `apps/web` | Веб-игра на Next.js 16 (статический экспорт): доска SVG, игра против компьютера (Web Worker) и вдвоём, UZ/RU/EN. |
| `docs/` | `RULES.md` — формализованные правила и открытые вопросы автору; `board-map.png` — карта доски; `source/` — исходные материалы. |

## Команды

```bash
npm install          # один раз, из корня
npm test             # тесты движка
npm run dev          # веб-версия на http://localhost:3000
npm run build        # статическая сборка в apps/web/out (для хостинга и Capacitor)
```

## Правила, которые трактованы нами (настраиваются в `RulesConfig`)

См. `docs/RULES.md`, раздел «Вопросы автору». Значения по умолчанию: фигура 3 — «1 прямо + 1 по диагонали»,
фигура 6 — обе ориентации «2+1», прыгуны 3/5/6 перепрыгивают, X ходит как римские, римские только вперёд,
зона «1» — 4 клетки (G1, F2, H2, G3 и зеркально), «1» может бить.
